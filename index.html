  1. 01

    Drop a file

    Drag it onto the chamber, paste it from the clipboard, or open the picker.

  2. 02

    Choose a target

    Images become WebP or PNG. CSV and TSV become JSON. Everything else returns a demo artifact.

This is a prototype. Image conversion and CSV → JSON run for real, locally, using browser APIs. PDF output and other pairings generate a clearly labelled demo artifact — a valid file, but not a true content conversion.
