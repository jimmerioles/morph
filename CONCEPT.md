# Morph — file alchemy

A file-converter landing page where the hero is the converter.

Drag a file onto the orb. It is shredded into glyphs, pulled through a glass machine, and rebuilt as another format. The output drops out with a satisfying ding. The animation is the product demo: any file in, any format out, locally.

## First build

1. Static page with a drop zone and format chips (PNG, PDF, CSV, MP4).
2. Canvas shred/rebuild animation for a sample file.
3. Real conversion for one pair (for example PNG → WebP) using a browser API.
4. Drag-and-drop, keyboard fallback, reduced-motion version.
5. A 60-second demo: drop a file, watch it transform, download the result.
